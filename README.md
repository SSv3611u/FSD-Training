# Responsive Student Management Portal

CampusBridge is a Bootstrap 5 student management portal built for Task 1 from the assignment PDF.

## Pages

- `index.html` - home page with navbar, carousel hero, feature cards, departments accordion, footer, and login modal.
- `registration.html` - student registration form with required fields, input group, file upload, checkbox, and Bootstrap validation.
- `dashboard.html` - statistics cards, searchable student table, badges, and responsive table layout.
- `profile.html` - student profile card and bonus student ID card.
- `contact.html` - contact form with success alert.

## Bootstrap Components Used

Navbar, grid system, typography, buttons, cards, forms, tables, alerts, badges, dropdown, collapse, accordion, modal, and carousel.

## How to Run

Open `index.html` in a browser. The project uses Bootstrap CDN links, so an internet connection is required for Bootstrap styles, scripts, and images.
